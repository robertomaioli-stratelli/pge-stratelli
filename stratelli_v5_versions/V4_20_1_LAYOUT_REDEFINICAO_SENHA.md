# INPACTA v4.20.1 — Layout da redefinição de senha

Evolução exclusivamente visual/UX da rota `/redefinir-senha/{token}`.

## Alterações
- identidade visual alinhada à tela de login;
- INPACTA By Stratelli no painel institucional;
- campos em coluna e responsivos;
- mostrar/ocultar senha;
- indicador visual de robustez;
- validação visual de coincidência entre senhas;
- aviso de segurança e invalidação de sessões antigas;
- tratamento visual específico para link expirado/inválido;
- layout adaptado para desktop, tablet e celular.
